## How to read the rows

- Where: report file and line (22 Oct 2026). Several lines are listed when the same gap appears in more than one chapter; all of them change together.
- Procedure: Setup / n (repetitions) / Pass / Ground truth (independent of the system under test) / Analysis (function expected in `BenchTest/analysis/`, Workstream C; names are proposals, the list at the end maps them).
- Pass criteria come from Table `tab:requirements-mapping` (Report/Introduction.tex:42 to 54) or `BenchTest/TEST_PROCEDURES.md` where those give one. Criteria marked [proposed] are new: the student fixes them in writing (commit this file) before run 2, and they are not changed after the data are seen.
- V&V: (ver) verification, it works as built; (val) validation, it measures what it should.
- Statistics used throughout: median, 95th percentile and maximum for timing; bootstrap 95 % confidence interval (10,000 resamples, percentile method) for a coefficient of variation (CV); ICC(2,1), two-way random effects, absolute agreement, single measure, with the F-based 95 % CI (McGraw and Wong, 1996), for repeatability; Wilson 95 % CI for proportions; Bland-Altman bias and 95 % limits of agreement for method comparison; ordinary least squares with a t-based 95 % CI for slopes. With n = 5 or 6 passes the CIs will be wide; the report states them rather than claiming power.
