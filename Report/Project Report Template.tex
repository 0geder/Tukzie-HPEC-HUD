{\Large Terms of Reference}\\

This project (SW-7) is to develop an embedded high-performance-computing telemetry unit and windshield head-up display for the TUKZIE Rev 0 electric cargo trike, capable of acquiring synchronised inertial, battery, positioning and camera data, characterising the vehicle's dynamic response at the edge, preserving telemetry under intermittent cellular connectivity, and presenting a minimal set of safety-relevant information to the driver.

{\Large Abstract}\\
\hrule

% Place your abstract here.
\textit{Draft abstract, to be revised once field results are available.}

This report describes the development of an embedded telemetry unit and windshield head-up display for the TUKZIE Rev 0, a 72\,V electric cargo trike. An ESP32-S3 with an integrated LTE modem acquires data from two inertial measurement units at 200\,Hz, the vehicle's battery-management system over Bluetooth Low Energy, and GNSS, computes time-domain ride-characterisation features at the edge, logs telemetry locally, and publishes it over MQTT. A Raspberry Pi 4 camera, time-synchronised to the inertial stream, provides a visual record, and an object detector reporting approximate distance bands has been implemented and run on live bench footage at about 7 frames per second, with distance calibration outstanding, to be complemented by a multi-zone time-of-flight sensor. Bench validation to date shows deterministic 200\,Hz acquisition with no dropped samples, per-sensor calibration reducing a 5 to 8\% disagreement between nominally identical accelerometers to within measurement noise, sub-second alignment between camera and inertial data, and a complete cellular publish path to a live broker. On-vehicle field testing, which the ride-characterisation and HUD research questions depend on, is the principal outstanding work.
